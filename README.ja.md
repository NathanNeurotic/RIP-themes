<h1 align="center">RIPPS2 テーマ</h1>

<p align="center"><b>コードに触れずに RIPPS2 の見た目を変える。</b><br>
RIPPS2 のどの見た目も、テーマフォルダー一つで変わります：<code>conf_theme.cfg</code>、8 ビット PNG、フォント、サウンド。<br>
ELF を作り直す必要はありません。ビルドに任せて、テーマを当てましょう。</p>

## テーマ一覧

| テーマ | 見た目 | 必要な RIPPS2 |
|---|---|---|
| **Adapt** / **Adapt Rx** | akilluminati47 の Adapt（RiptOPL）：各ゲームのアートをすりガラスの下に（16:9 で伸ばさず拡大）、左に Adapt のサイドバーをすりガラスの帯として、片側に RIPPS2 のケースに入ったゲームのカバーと反射、それにディスク、反対側に透明ガラスのリスト（Rx はリストとケースを入れ替え、LAUNCH DISC をバーの右、ディスクの上に置きます）。ディスクは常に LAUNCH DISC のすぐ下。情報ページは 4:3 スクリーンショット付きの透明ガラスで、右スティックで一枚のシートとして傾きます。ページ間のトランジション、柱の上の設定画面、ゲームページにはタワーなし。独自のサウンドはなし（2026/10/12 から）：AUDIO フォルダーにリッピングした音が鳴ります。ソース名がポップインします（build 81 からトースト表示：ALL GAMES、HDD GAMES...）。エディション 113 から三つのカテゴリーはすりガラスのサイドバー上のグリフ（`category_layout=sidebar`、build 113）：リストで左を押すと、それぞれの引き出しが隣に開きます。エディション 115 から、各テーマは自分の `conf_theme.cfg` と `SCR43.png` だけ。リストのケースは表カバー、次に裏カバーをクロスフェードで表示し、情報ページはテキストをリストと反対側に置きます（Adapt は右、Adapt Rx は左）。 | build 80 |
| **RIPGRID** *（build 91 から RIPPS2 に内蔵：設定 > インターフェース > テーマで選択）* | Adapt のすりガラス画面とサイドバーに、ゲームを中央寄せの 4x2 カバーグリッドで。選択中はやわらかく光りながら呼吸し、右スティックで傾きます。カバーのないゲームはシリアルをピクセル文字で表示し、○ボタンでソースを切り替えます。右スティックを 0.42 秒倒し続けると選んだケースが裏返り（build 97。裏のまま）、ページは L2 / R2 か行の端で出入りし、起動時にはゲームのディスクがポップインし、選んだゲームの名前がグリッドの下に RIPPS2 Sleek Bold で表示されます。ELF に入っているので、このパックにはもう含まれません。 | 内蔵 |

インストール：`thm_...` フォルダーを、ドライブ（USB、HDD、MMCE、メモリーカード）の `THM` フォルダーにコピーします（ほかの OPL テーマと同じ）。そのあと RIPPS2 の設定 > インターフェース > テーマで選ぶか、ゲームリストで SELECT を 4.2 秒押し続けてテーマを順に切り替えます。RIPGRID と RIPFLOW は最初から入っています。

ここにある `conf_theme.cfg` はどれも、作成ヘッダー（名前、作者、作成日と更新日、クレジット）、続いて **キー用語集**（[docs/key_glossary.cfg](docs/key_glossary.cfg)：テーマが使えるすべてのキーをコメントで）、そしてテーマ本体の順で始まります。用語集を自分のテーマの設定にコピーしておくと便利です。

### 本体での操作
- ゲームリストで **SELECT を 4.2 秒押し続ける**と次のテーマへ（短く押すと今までどおりリストを更新）。
- **右スティック**でアートが傾きます：情報ページ全体を一枚の面として、Adapt のケースとディスク、RIPGRID の選択中カバー。
- **RIPGRID**（内蔵）：方向キーでグリッドを移動、行の端でページ送り。**○ボタン**でソース切り替え（USB、HDD、ALL GAMES...）。

## 自分で作る

**[docs/THEME_KEYS.md](docs/THEME_KEYS.md) は RIPPS2 build 100 時点のエンジンのすべて**で、すべてテーマフォルダーから使えます：

| | テーマにできること |
|---|---|
| **見た目** | 各ゲームのアートの上のすりガラスパネル、全画面のすりガラス層、サイドバー、透明ガラス、カバーの**グリッド**、反射付きの RIPPS2 ケース、16:9 上の 4:3 スクリーンショット、横長にトリミングした背景、タワーのオン・オフ。 |
| **動き** | ページ全体（または一枚のカバー）をシートのように動かす右スティックの傾き、リストと情報ページ間のトランジション、ふわりと入るアート、流れる説明文、情報ページのスライドショー、トーストで出るソース名。 |
| **フォント** | 16 のフォント枠。自分の `.ttf` か RIPPS2 の内蔵書体、大文字にするかどうかも。RIPPS2 が自分のページを描く枠なので、テーマでメニュー、カテゴリーバー、ビュー語のスタイルも変わります。 |
| **色** | テーマの色と、独自の **Colors and More**：カラーテーマ（RIPPS2、Ember、Blood、Ectoplasm、Amethyst、Bone）、カテゴリーバー、ヒント、グリフ、カテゴリーの順序。最後に決めるのは常にユーザーです。 |
| **画像** | RIPPS2 自身の画像（ボタングリフ、バッジ、読み込み表示、飛ぶマーク、PS1 / PS2 ロゴ）は、同じ名前の PNG を入れるだけで置き換えられます。 |
| **サウンド** | 15 のイベント（起動、カーソル、決定、ページの出入り、起動演出、ディスク...）のどれでも入れられる `sound/` フォルダーと、独自の音楽用の `sound/bgm.ogg`。 |

## キット

| | |
|---|---|
| [AGENTS.md](AGENTS.md) | ルール：最初に読んでください。 |
| [docs/THEME_KEYS.md](docs/THEME_KEYS.md) | RIPPS2 のエンジンがテーマのためにすること：キー、要素、フォント、エフェクト、画像、サウンド。 |
| [docs/THEME_ENGINE_RiptOPL.md](docs/THEME_ENGINE_RiptOPL.md) | その下のエンジン（RiptOPL のリファレンス）。 |
| [docs/key_glossary.cfg](docs/key_glossary.cfg) | すべてのキーを 1 ページに、`#` コメントで：ここにある各 `conf_theme.cfg` の先頭の用語集です。 |
| `tools/check_theme.py` | 読み込めるか？ 番号、型、足りないファイル、場所違いのキー、RIPPS2 が知っている値、8 ビット画像。 |
| `tools/mirror_theme.py` | テーマの左右反転レイアウトの下書きを作ります。 |
| `tools/png8.py` | すべての画像を 8 ビットパレットの PNG に：RIPPS2 は 8 ビットテクスチャとして、VRAM の 4 分の 1 で保持します。 |
| `tools/gen_adapt_family.py` | 一つのレイアウトから Adapt と Adapt Rx を、それぞれヘッダーと用語集付きで書き出します（編集するのはこちらで、`conf_theme.cfg` ではありません。変更したら `EDITION_DATE` を設定）。 |

```
python3 tools/check_theme.py themes/*
python3 tools/png8.py themes/thm_MyTheme
python3 tools/mirror_theme.py "themes/thm_Adapt" "themes/thm_Adapt Rx" "Adapt Rx"
```
`png8.py` には Pillow と numpy 付きの Python 3（`pip install pillow numpy`）。あとは実際に見てください：テーマを仮想ドライブに置いた PCSX2（System > Start File、RIPPS2.elf）か、PS2 で。
