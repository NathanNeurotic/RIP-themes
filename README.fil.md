<h1 align="center">Mga tema ng RIPPS2</h1>

<p align="center"><b>Bihisan ang RIPPS2 nang hindi ginagalaw ang code nito.</b><br>
Bawat itsura ng RIPPS2 ay isang theme folder lang ang layo: isang <code>conf_theme.cfg</code>, mga 8-bit na PNG, mga font at mga tunog.<br>
Walang ELF na kailangang i-build ulit. Umasa sa build, bigyan ito ng tema.</p>

## Ang mga tema

| Tema | Itsura | Kailangang RIPPS2 |
|---|---|---|
| **Adapt** / **Adapt Rx** | Ang Adapt ni akilluminati47 (RiptOPL): ang larawan ng bawat laro sa ilalim ng frosted glass (pinalaki, hindi binanat, sa 16:9) na may sidebar ng Adapt bilang frosted na guhit sa kaliwa, ang cover ng laro sa case ng RIPPS2 kasama ang repleksiyon nito at ang disc sa isang gilid, ang listahan sa malinaw na salamin sa kabila (pinagpapalit ng Rx ang listahan at ang case, at inilalagay ang LAUNCH DISC sa kanan ng bar, sa ibabaw ng disc nito). Laging nasa ilalim mismo ng LAUNCH DISC ang disc. Info page sa malinaw na salamin na may 4:3 na screenshot, na tumatagilid sa kanang stick bilang iisang pahina; transisyon sa pagitan ng mga pahina, Settings sa ibabaw ng mga haligi, walang tore sa mga pahina ng laro. Walang sariling tunog (mula 12/10/2026): ang mga tunog na ni-rip mo sa AUDIO folder ang tumutugtog. Biglang lumilitaw ang pangalan ng source (mula build 81 bilang abiso: ALL GAMES, HDD GAMES...). Mula edisyon 113, glyph sa frosted na sidebar ang tatlong kategorya (`category_layout=sidebar`, build 113): binubuksan ng Kaliwa sa listahan ang drawer ng bawat isa sa tabi nito. Mula edisyon 115, ang bawat tema ay ang `conf_theme.cfg` at `SCR43.png` nito. Ipinapakita ng case sa listahan ang harapang cover, saka ang likod, na may crossfade; inilalagay ng info page ang teksto nito sa kabilang gilid ng listahan (Adapt sa kanan, Adapt Rx sa kaliwa). | build 80 |
| **RIPGRID** *(nakapaloob sa RIPPS2 mula build 91: piliin sa Settings > Interface > Theme)* | Ang frosted na screen at sidebar ng Adapt, ang mga laro ay nasa nakagitnang 4x2 na grid ng mga cover; humihinga ang napili nang may malambot na liwanag at tumatagilid sa kanang stick, ipinapakita ng mga larong walang cover ang serial nila sa pixel na letra, at pinapalitan ng Bilog ang mga source. Ang pagpindot sa kanang stick nang 0.42 s ay binabaligtad ang napiling case sa likod na cover nito (build 97; nananatili itong baligtad), pumapasok at lumalabas ang mga pahina sa L2 / R2 o sa gilid ng isang hanay, lumilitaw ang disc ng laro pagsisimula nito, at nasa ilalim ng grid ang pangalan ng napiling laro sa RIPPS2 Sleek Bold. Kasama na ito sa ELF, kaya wala na ito sa pack na ito. | built-in |

Pag-install: kopyahin ang isang `thm_...` folder sa isang `THM` folder sa iyong drive (USB, HDD, MMCE, memory card), gaya ng anumang tema ng OPL, saka piliin ito sa Settings > Interface > Theme ng RIPPS2, o pindutin nang matagal ang SELECT sa listahan ng laro nang 4.2 segundo para lumipat-lipat ng tema. Naroon na ang RIPGRID at RIPFLOW.

Bawat `conf_theme.cfg` dito ay nagsisimula sa header ng paglikha nito (pangalan, gumawa, petsa ng paglikha at pag-update, pasasalamat), saka ang **glosaryo ng mga key** ([docs/key_glossary.cfg](docs/key_glossary.cfg): bawat key na magagamit ng tema, bilang mga komento), saka ang tema. Kopyahin ang glosaryo sa config ng sarili mong tema para laging nasa kamay.

<a id="on-the-console"></a>

### Sa console
- **Pindutin nang matagal ang SELECT nang 4.2 segundo** sa listahan ng laro para lumipat sa susunod na tema (nire-refresh pa rin ng mabilis na pindot ang listahan).
- **Ang kanang stick** ang nagpapatagilid sa larawan: ang buong info page bilang iisang patag, ang case at disc ng Adapt, ang napiling cover ng RIPGRID.
- **RIPGRID** (built-in): gumagalaw ang D-pad sa grid, binubuklat ng gilid ng hanay ang pahina; pinapalitan ng **Bilog** ang mga source (USB, HDD, ALL GAMES...).

<a id="make-your-own"></a>

## Gumawa ng sarili mo

**Ang [docs/THEME_KEYS.md](docs/THEME_KEYS.md) ang buong engine, ayon sa RIPPS2 build 100**, lahat ay maaabot mula sa isang theme folder:

| | Ang kayang gawin ng tema |
|---|---|
| **Itsura** | Mga panel ng frosted glass sa ibabaw ng larawan ng bawat laro, isang full-screen na frosted na layer, mga sidebar, malinaw na salamin, isang **grid** ng mga cover, ang case ng RIPPS2 na may repleksiyon, 4:3 na screenshot sa 16:9, malapad na ginupit na background, may tore o wala. |
| **Galaw** | Pagtagilid sa kanang stick na gumagalaw sa buong pahina bilang iisang sheet (o iisang cover), transisyon sa pagitan ng listahan at info page, larawang dahan-dahang pumapasok, deskripsiyong gumugulong, slideshow sa info page, ang pangalan ng source bilang abiso. |
| **Mga font** | 16 na slot ng font, ang iyong `.ttf` o ang mga built-in na font ng RIPPS2, naka-capital o hindi; ang mga slot na ginagamit ng RIPPS2 sa pagguhit ng sarili nitong mga pahina, kaya binabago rin ng tema ang estilo ng mga menu, ng category bar at ng salita ng view. |
| **Kulay** | Ang mga kulay ng tema at ang sarili nitong **Colors and More**: color theme (RIPPS2, Ember, Blood, Ectoplasm, Amethyst, Bone), category bar, mga hint, mga glyph, ayos ng mga kategorya. Laging nasa user ang huling salita. |
| **Mga larawan** | Alinman sa mga sariling larawan ng RIPPS2 (mga glyph ng button, badge, loader, ang lumilipad na marka, ang logo ng PS1 / PS2) ay napapalitan sa pagsama ng PNG na may parehong pangalan. |
| **Tunog** | Isang `sound/` folder na may alinman sa 15 kaganapan (boot, cursor, confirm, pagpasok at paglabas ng pahina, launch, disc...) at `sound/bgm.ogg` para sa sarili nitong musika. |

<a id="the-kit"></a>

## Ang kit

| | |
|---|---|
| [AGENTS.md](AGENTS.md) | Ang mga patakaran: basahin muna. |
| [docs/THEME_KEYS.md](docs/THEME_KEYS.md) | Lahat ng ginagawa ng engine ng RIPPS2 para sa isang tema: mga key, elemento, font, epekto, larawan, tunog. |
| [docs/THEME_ENGINE_RiptOPL.md](docs/THEME_ENGINE_RiptOPL.md) | Ang engine sa ilalim (ang sanggunian ng RiptOPL). |
| [docs/key_glossary.cfg](docs/key_glossary.cfg) | Bawat key sa iisang pahina, bilang mga komentong `#`: ang glosaryo sa itaas ng bawat `conf_theme.cfg` dito. |
| `tools/check_theme.py` | Maglo-load ba? Pagnunumero, mga uri, nawawalang file, maling lugar na key, mga value na kilala ng RIPPS2, mga 8-bit na larawan. |
| `tools/mirror_theme.py` | Gumagawa ng burador ng nakasalaming layout ng isang tema. |
| `tools/png8.py` | Ginagawang 8-bit na palette PNG ang bawat larawan: iniingatan ng RIPPS2 ang mga ito bilang 8-bit na texture, sangkapat ng VRAM. |
| `tools/gen_adapt_family.py` | Isinusulat ang Adapt at Adapt Rx mula sa iisang layout, bawat isa may header at glosaryo (ito ang i-edit, hindi ang `conf_theme.cfg` nila; itakda ang `EDITION_DATE` nito kapag nagbago sila). |

```
python3 tools/check_theme.py themes/*
python3 tools/png8.py themes/thm_MyTheme
python3 tools/mirror_theme.py "themes/thm_Adapt" "themes/thm_Adapt Rx" "Adapt Rx"
```
Python 3, kasama ang Pillow at numpy (`pip install pillow numpy`) para sa `png8.py`. Saka tingnan ito nang totoo: sa PCSX2 (System > Start File, RIPPS2.elf) na nasa virtual drive nito ang tema, o sa isang PS2.
