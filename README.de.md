<h1 align="center">RIPPS2-Themes</h1>

<p align="center"><b>Gestalte RIPPS2, ohne seinen Code anzufassen.</b><br>
Jeder Look in RIPPS2 ist nur einen Theme-Ordner entfernt: eine <code>conf_theme.cfg</code>, 8-Bit-PNGs, Schriften und Sounds.<br>
Kein ELF neu bauen. Verlass dich auf den Build, gib ihm ein Theme.</p>

## Die Themes

| Theme | Look | Braucht RIPPS2 |
|---|---|---|
| **Adapt** / **Adapt Rx** | akilluminati47s Adapt (RiptOPL): die Grafik jedes Spiels unter Milchglas (vergrößert, nicht gestreckt, in 16:9) mit Adapts Seitenleiste als Milchglasstreifen links, das Cover des Spiels in RIPPS2s Hülle mit Spiegelung und die Disc auf der einen Seite, die Liste auf klarem Glas auf der anderen (Rx tauscht Liste und Hülle und setzt LAUNCH DISC rechts an die Leiste, über ihre Disc). Die Disc sitzt immer direkt unter LAUNCH DISC. Infoseite auf klarem Glas mit 4:3-Screenshots, die mit dem rechten Stick als ein Blatt kippt; Seitenübergänge, Einstellungen über den Säulen, keine Türme auf den Spielseiten. Keine eigenen Sounds (seit 12.10.2026): es spielen die Rips aus deinem AUDIO-Ordner. Der Quellenname springt herein (ab Build 81 als Toast: ALL GAMES, HDD GAMES...). Ab Edition 113 sind die drei Kategorien Glyphen in der Milchglas-Seitenleiste (`category_layout=sidebar`, Build 113): Links auf der Liste öffnet die Schublade jeder Kategorie daneben. Ab Edition 115 ist jedes Theme seine `conf_theme.cfg` und seine `SCR43.png`. Die Hülle der Liste zeigt das Cover, dann die Rückseite, überblendend; die Infoseite setzt ihren Text auf die andere Seite als die Liste (Adapt rechts, Adapt Rx links). | Build 80 |
| **RIPGRID** *(seit Build 91 in RIPPS2 eingebaut: wähle es unter Einstellungen > Oberfläche > Theme)* | Adapts Milchglasbildschirm und Seitenleiste mit den Spielen als zentriertes 4x2-Cover-Raster; die Auswahl atmet mit sanftem Leuchten und kippt mit dem rechten Stick, Spiele ohne Cover zeigen ihre Seriennummer in Pixelschrift, und Kreis schaltet durch die Quellen. Hältst du den rechten Stick 0,42 s, dreht sich die gewählte Hülle auf ihre Rückseite (Build 97; sie bleibt gedreht), Seiten gleiten mit L2 / R2 oder am Rand einer Reihe hinein und hinaus, die Disc des Spiels springt beim Start herein, und der Name des gewählten Spiels steht in RIPPS2 Sleek Bold unter dem Raster. Es steckt im ELF und ist deshalb nicht mehr in diesem Paket. | eingebaut |

Installation: kopiere einen `thm_...`-Ordner in einen `THM`-Ordner auf deinem Laufwerk (USB, HDD, MMCE, Memory Card), wie bei jedem OPL-Theme, und wähle es dann in RIPPS2 unter Einstellungen > Oberfläche > Theme, oder halte SELECT auf der Spieleliste 4,2 Sekunden, um durch die Themes zu schalten. RIPGRID und RIPFLOW sind schon da.

Jede `conf_theme.cfg` hier beginnt mit ihrem Erstellungskopf (Name, Autor, Erstell- und Änderungsdatum, Credits), dann dem **Schlüssel-Glossar** ([docs/key_glossary.cfg](docs/key_glossary.cfg): jeder Schlüssel, den ein Theme nutzen kann, als Kommentar), dann dem Theme. Kopiere das Glossar in die Konfiguration deines eigenen Themes, um es griffbereit zu haben.

<a id="on-the-console"></a>

### Auf der Konsole
- **Halte SELECT 4,2 Sekunden** auf der Spieleliste, um zum nächsten Theme zu wechseln (ein kurzer Druck aktualisiert weiterhin die Liste).
- **Der rechte Stick** kippt die Grafik: die ganze Infoseite als eine Ebene, Adapts Hülle und Disc, RIPGRIDs gewähltes Cover.
- **RIPGRID** (eingebaut): das Steuerkreuz bewegt sich durch das Raster, der Rand einer Reihe blättert die Seite um; **Kreis** schaltet durch die Quellen (USB, HDD, ALL GAMES...).

<a id="make-your-own"></a>

## Mach dein eigenes

**[docs/THEME_KEYS.md](docs/THEME_KEYS.md) ist die ganze Engine, Stand RIPPS2 Build 100**, alles aus einem Theme-Ordner erreichbar:

| | Was ein Theme kann |
|---|---|
| **Look** | Milchglasflächen über der Grafik jedes Spiels, eine bildschirmfüllende Milchglasebene, Seitenleisten, klares Glas, ein Cover-**Raster**, RIPPS2s Hülle mit Spiegelung, 4:3-Screenshots auf 16:9, breit beschnittene Hintergründe, Türme an oder aus. |
| **Bewegung** | Kippen mit dem rechten Stick, das eine ganze Seite als ein Blatt bewegt (oder ein Cover), Übergänge zwischen Liste und Infoseite, sanft einblendende Grafik, laufende Beschreibungen, Diashows auf der Infoseite, der Quellenname als Toast. |
| **Schriften** | 16 Schriftplätze, deine `.ttf` oder RIPPS2s eingebaute Schriften, in Großbuchstaben oder nicht; die Plätze, mit denen RIPPS2 seine eigenen Seiten zeichnet, sodass ein Theme auch Menüs, Kategorieleiste und Ansichtswort umgestaltet. |
| **Farbe** | Die Farben des Themes und sein eigenes **Colors and More**: Farbthema (RIPPS2, Ember, Blood, Ectoplasm, Amethyst, Bone), Kategorieleiste, Hinweise, Glyphen, Reihenfolge der Kategorien. Das letzte Wort hat immer der Nutzer. |
| **Bilder** | Jedes von RIPPS2s eigenen Bildern (Tastenglyphen, Abzeichen, Ladeanzeigen, das fliegende Zeichen, die PS1- / PS2-Logos), ersetzt durch ein mitgeliefertes PNG gleichen Namens. |
| **Sound** | Ein `sound/`-Ordner mit beliebigen der 15 Ereignisse (Start, Cursor, Bestätigen, Seite rein und raus, Spielstart, Disc...) und `sound/bgm.ogg` für eigene Musik. |

<a id="the-kit"></a>

## Das Kit

| | |
|---|---|
| [AGENTS.md](AGENTS.md) | Die Regeln: zuerst lesen. |
| [docs/THEME_KEYS.md](docs/THEME_KEYS.md) | Alles, was RIPPS2s Engine für ein Theme tut: Schlüssel, Elemente, Schriften, Effekte, Bilder, Sounds. |
| [docs/THEME_ENGINE_RiptOPL.md](docs/THEME_ENGINE_RiptOPL.md) | Die Engine darunter (RiptOPLs Referenz). |
| [docs/key_glossary.cfg](docs/key_glossary.cfg) | Jeder Schlüssel auf einer Seite, als `#`-Kommentare: das Glossar oben in jeder `conf_theme.cfg` hier. |
| `tools/check_theme.py` | Lädt es? Nummerierung, Typen, fehlende Dateien, falsch platzierte Schlüssel, Werte, die RIPPS2 kennt, 8-Bit-Bilder. |
| `tools/mirror_theme.py` | Entwirft das spiegelverkehrte Layout eines Themes. |
| `tools/png8.py` | Macht jedes Bild zu einem 8-Bit-Paletten-PNG: RIPPS2 hält sie als 8-Bit-Texturen, ein Viertel des VRAM. |
| `tools/gen_adapt_family.py` | Schreibt Adapt und Adapt Rx aus einem Layout, jedes mit seinem Kopf und dem Glossar (bearbeite dieses, nicht ihre `conf_theme.cfg`; setze sein `EDITION_DATE`, wenn sie sich ändern). |

```
python3 tools/check_theme.py themes/*
python3 tools/png8.py themes/thm_MyTheme
python3 tools/mirror_theme.py "themes/thm_Adapt" "themes/thm_Adapt Rx" "Adapt Rx"
```
Python 3, mit Pillow und numpy (`pip install pillow numpy`) für `png8.py`. Dann sieh es dir echt an: in PCSX2 (System > Start File, RIPPS2.elf) mit dem Theme auf seinem virtuellen Laufwerk, oder auf einer PS2.
