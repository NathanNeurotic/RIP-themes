<h1 align="center">RIPPS2 主题</h1>

<p align="center"><b>不碰代码，就能给 RIPPS2 换主题。</b><br>
RIPPS2 的每种外观都只差一个主题文件夹：一个 <code>conf_theme.cfg</code>、8 位 PNG、字体和音效。<br>
无需重新编译 ELF。交给构建，给它换上主题。</p>

<a id="the-themes"></a>

## 主题

| 主题 | 外观 | 需要的 RIPPS2 |
|---|---|---|
| **Adapt** / **Adapt Rx** | akilluminati47 的 Adapt（RiptOPL）：每个游戏的美术图在磨砂玻璃下（在 16:9 中放大而非拉伸），左侧是 Adapt 的侧边栏，呈磨砂条带；一边是装在 RIPPS2 游戏盒里的游戏封面及其倒影和光盘，另一边是透明玻璃上的列表（Rx 交换列表和游戏盒，并把 LAUNCH DISC 放在侧边栏右侧、光盘上方）。光盘总在 LAUNCH DISC 的正下方。信息页是带 4:3 截图的透明玻璃，用右摇杆像一张纸一样倾斜；页面间有过渡，设置界面在柱子之上，游戏页没有塔。没有自带音效（自 2026/10/12 起）：播放你提取到 AUDIO 文件夹的声音。来源名称会弹出（自 build 81 起以提示形式：ALL GAMES、HDD GAMES...）。自第 113 版起，三个分类是磨砂侧边栏中的图标（`category_layout=sidebar`，build 113）：在列表上按左，会在旁边打开各自的抽屉。自第 115 版起，每个主题只有它的 `conf_theme.cfg` 和 `SCR43.png`。列表中的游戏盒先显示正面封面，再以交叉淡化显示背面；信息页把文字放在与列表相反的一侧（Adapt 在右，Adapt Rx 在左）。 | build 80 |
| **RIPGRID** *（自 build 91 起内置于 RIPPS2：在 设置 > 界面 > 主题 中选择）* | Adapt 的磨砂屏幕和侧边栏，游戏以居中的 4x2 封面网格排列；选中项带柔和光晕呼吸，并随右摇杆倾斜，没有封面的游戏以像素字体显示序列号，圆圈键切换来源。按住右摇杆 0.42 秒会把选中的游戏盒翻到背面（build 97；保持翻转），页面随 L2 / R2 或在一行的边缘滑入滑出，启动时游戏光盘会弹出，选中游戏的名称以 RIPPS2 Sleek Bold 显示在网格下方。它随 ELF 一起提供，所以不再包含在这个包里。 | 内置 |

安装：把一个 `thm_...` 文件夹复制到你设备（USB、HDD、MMCE、记忆卡）上的 `THM` 文件夹中，和任何 OPL 主题一样；然后在 RIPPS2 的 设置 > 界面 > 主题 中选择，或在游戏列表上按住 SELECT 4.2 秒依次切换主题。RIPGRID 和 RIPFLOW 已经在里面。

这里的每个 `conf_theme.cfg` 都以创建标头开头（名称、作者、创建和更新日期、致谢），然后是 **键名词汇表**（[docs/key_glossary.cfg](docs/key_glossary.cfg)：主题能用的每个键，以注释形式），最后是主题本身。把词汇表复制到你自己主题的配置里，方便随时查阅。

<a id="on-the-console"></a>

### 在主机上
- 在游戏列表上**按住 SELECT 4.2 秒**切换到下一个主题（短按仍然刷新列表）。
- **右摇杆**让美术图倾斜：整个信息页作为一个平面、Adapt 的游戏盒和光盘、RIPGRID 中选中的封面。
- **RIPGRID**（内置）：方向键在网格中移动，一行的边缘会翻页；**圆圈键**切换来源（USB、HDD、ALL GAMES...）。

<a id="make-your-own"></a>

## 自己做一个

**[docs/THEME_KEYS.md](docs/THEME_KEYS.md) 涵盖整个引擎，截至 RIPPS2 build 100**，全部都能从主题文件夹使用：

| | 主题能做什么 |
|---|---|
| **外观** | 每个游戏美术图上方的磨砂玻璃面板、全屏磨砂层、侧边栏、透明玻璃、封面**网格**、带倒影的 RIPPS2 游戏盒、16:9 上的 4:3 截图、宽幅裁切背景、开关塔。 |
| **动效** | 右摇杆倾斜，把整页（或一张封面）像一张纸一样移动；列表与信息页之间的过渡、柔和淡入的美术图、滚动的简介、信息页幻灯片、以提示形式出现的来源名称。 |
| **字体** | 16 个字体槽，你自己的 `.ttf` 或 RIPPS2 的内置字体，可选是否大写；这些正是 RIPPS2 绘制自身页面所用的槽，所以主题也会改变菜单、分类栏和视图词的样式。 |
| **颜色** | 主题的颜色以及它自己的 **Colors and More**：配色主题（RIPPS2、Ember、Blood、Ectoplasm、Amethyst、Bone）、分类栏、提示、图标、分类顺序。最终决定权始终在用户手中。 |
| **图片** | RIPPS2 自带的任何图片（按键图标、徽章、加载指示、飞行标记、PS1 / PS2 标志），只要放入同名 PNG 即可替换。 |
| **声音** | 一个 `sound/` 文件夹，可包含 15 个事件中的任何一个（开机、光标、确认、进出页面、启动、光盘...），以及用于自带音乐的 `sound/bgm.ogg`。 |

<a id="the-kit"></a>

## 工具包

| | |
|---|---|
| [AGENTS.md](AGENTS.md) | 规则：请先读。 |
| [docs/THEME_KEYS.md](docs/THEME_KEYS.md) | RIPPS2 引擎为主题所做的一切：键、元素、字体、特效、图片、声音。 |
| [docs/THEME_ENGINE_RiptOPL.md](docs/THEME_ENGINE_RiptOPL.md) | 底层的引擎（RiptOPL 的参考文档）。 |
| [docs/key_glossary.cfg](docs/key_glossary.cfg) | 所有键都在一页上，以 `#` 注释形式：就是这里每个 `conf_theme.cfg` 开头的词汇表。 |
| `tools/check_theme.py` | 能加载吗？编号、类型、缺失文件、放错位置的键、RIPPS2 认识的值、8 位图片。 |
| `tools/mirror_theme.py` | 起草主题的左右镜像布局。 |
| `tools/png8.py` | 把每张图片转成 8 位调色板 PNG：RIPPS2 以 8 位纹理保存，只占四分之一的 VRAM。 |
| `tools/gen_adapt_family.py` | 从一个布局写出 Adapt 和 Adapt Rx，各带标头和词汇表（改这个文件，不要改它们的 `conf_theme.cfg`；改动时设置它的 `EDITION_DATE`）。 |

```
python3 tools/check_theme.py themes/*
python3 tools/png8.py themes/thm_MyTheme
python3 tools/mirror_theme.py "themes/thm_Adapt" "themes/thm_Adapt Rx" "Adapt Rx"
```
`png8.py` 需要带 Pillow 和 numpy 的 Python 3（`pip install pillow numpy`）。然后真正看一看：在 PCSX2（System > Start File，RIPPS2.elf）里把主题放在虚拟驱动器上，或在 PS2 上。
