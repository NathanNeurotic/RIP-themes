<h1 align="center">Темы для RIPPS2</h1>

<p align="center"><b>Оформляйте RIPPS2, не трогая его код.</b><br>
Любой облик RIPPS2 находится в одной папке темы: <code>conf_theme.cfg</code>, 8-битные PNG, шрифты и звуки.<br>
Никакой пересборки ELF. Положитесь на сборку, дайте ей тему.</p>

## Темы

| Тема | Облик | Нужен RIPPS2 |
|---|---|---|
| **Adapt** / **Adapt Rx** | Adapt от akilluminati47 (RiptOPL): арт каждой игры под матовым стеклом (увеличенный, не растянутый, в 16:9) с боковой панелью Adapt в виде матовой полосы слева, обложка игры в коробке RIPPS2 с отражением и диск с одной стороны, список на прозрачном стекле с другой (Rx меняет местами список и коробку и ставит LAUNCH DISC справа на панели, над её диском). Диск всегда находится прямо под LAUNCH DISC. Страница информации на прозрачном стекле со скриншотами 4:3, наклоняется правым стиком как один лист; переходы между страницами, Настройки поверх колонн, без башен на страницах игр. Своих звуков нет (с 12.10.2026): звучат ваши рипы из папки AUDIO. Имя источника всплывает (с билда 81 как уведомление: ALL GAMES, HDD GAMES...). С выпуска 113 три категории — это глифы на матовой боковой панели (`category_layout=sidebar`, билд 113): Влево в списке открывает рядом ящик каждой из них. С выпуска 115 каждая тема — это её `conf_theme.cfg` и её `SCR43.png`. Коробка в списке показывает лицевую сторону, затем оборот, с переходом; страница информации ставит текст с противоположной от списка стороны (Adapt справа, Adapt Rx слева). | билд 80 |
| **RIPGRID** *(встроен в RIPPS2 с билда 91: выберите его в Настройки > Интерфейс > Тема)* | Матовый экран и боковая панель Adapt с играми в центрированной сетке обложек 4x2; выбранная обложка «дышит» мягким свечением и наклоняется правым стиком, игры без обложки показывают серийный номер пиксельным шрифтом, а Круг переключает источники. Удержание правого стика 0,42 с поворачивает выбранную коробку оборотом (билд 97; она так и остаётся), страницы въезжают и уезжают по L2 / R2 или у края ряда, диск игры всплывает при запуске, а название выбранной игры стоит под сеткой шрифтом RIPPS2 Sleek Bold. Он поставляется внутри ELF, поэтому в этом наборе его больше нет. | встроен |

Установка: скопируйте папку `thm_...` в папку `THM` на своём носителе (USB, HDD, MMCE, карта памяти), как любую тему OPL, затем выберите её в RIPPS2 в Настройки > Интерфейс > Тема или удерживайте SELECT в списке игр 4,2 секунды, чтобы перебирать темы. RIPGRID и RIPFLOW уже там.

Каждый `conf_theme.cfg` здесь начинается с заголовка создания (название, автор, даты создания и обновления, благодарности), затем идёт **словарь ключей** ([docs/key_glossary.cfg](docs/key_glossary.cfg): каждый ключ, который может использовать тема, в виде комментариев), затем сама тема. Скопируйте словарь в конфигурацию своей темы, чтобы он был под рукой.

### На консоли
- **Удерживайте SELECT 4,2 секунды** в списке игр, чтобы перейти к следующей теме (короткое нажатие по-прежнему обновляет список).
- **Правый стик** наклоняет арт: всю страницу информации как одну плоскость, коробку и диск Adapt, выбранную обложку RIPGRID.
- **RIPGRID** (встроен): крестовина двигается по сетке, край ряда перелистывает страницу; **Круг** переключает источники (USB, HDD, ALL GAMES...).

## Сделайте свою

**[docs/THEME_KEYS.md](docs/THEME_KEYS.md) описывает весь движок по состоянию на билд 100 RIPPS2**, и всё это доступно из папки темы:

| | Что может тема |
|---|---|
| **Облик** | Панели из матового стекла поверх арта каждой игры, матовый слой на весь экран, боковые панели, прозрачное стекло, **сетка** обложек, коробка RIPPS2 с отражением, скриншоты 4:3 на 16:9, фоны с широкой обрезкой, башни есть или нет. |
| **Движение** | Наклон правым стиком, который двигает целую страницу как один лист (или одну обложку), переходы между списком и страницей информации, плавно появляющийся арт, прокручивающиеся описания, слайд-шоу на странице информации, имя источника как уведомление. |
| **Шрифты** | 16 слотов для шрифтов, ваш `.ttf` или встроенные шрифты RIPPS2, прописными или нет; слоты, которыми RIPPS2 рисует свои страницы, так что тема меняет и стиль меню, панели категорий и слова вида. |
| **Цвет** | Цвета темы и её собственное **Colors and More**: цветовая тема (RIPPS2, Ember, Blood, Ectoplasm, Amethyst, Bone), панель категорий, подсказки, глифы, порядок категорий. Последнее слово всегда за пользователем. |
| **Изображения** | Любое из изображений RIPPS2 (глифы кнопок, значки, индикаторы загрузки, летящий знак, логотипы PS1 / PS2) заменяется, если положить PNG с тем же именем. |
| **Звук** | Папка `sound/` с любым из 15 событий (запуск, курсор, подтверждение, вход и выход со страницы, запуск игры, диск...) и `sound/bgm.ogg` для своей музыки. |

## Набор

| | |
|---|---|
| [AGENTS.md](AGENTS.md) | Правила: прочитайте первым делом. |
| [docs/THEME_KEYS.md](docs/THEME_KEYS.md) | Всё, что движок RIPPS2 делает для темы: ключи, элементы, шрифты, эффекты, изображения, звуки. |
| [docs/THEME_ENGINE_RiptOPL.md](docs/THEME_ENGINE_RiptOPL.md) | Движок под ним (справочник RiptOPL). |
| [docs/key_glossary.cfg](docs/key_glossary.cfg) | Каждый ключ на одной странице, в виде комментариев `#`: словарь в начале каждого `conf_theme.cfg` здесь. |
| `tools/check_theme.py` | Загрузится ли? Нумерация, типы, недостающие файлы, ключи не на месте, значения, известные RIPPS2, 8-битные изображения. |
| `tools/mirror_theme.py` | Набрасывает зеркальную раскладку темы. |
| `tools/png8.py` | Делает каждое изображение 8-битным PNG с палитрой: RIPPS2 держит их как 8-битные текстуры, четверть VRAM. |
| `tools/gen_adapt_family.py` | Записывает Adapt и Adapt Rx из одной раскладки, каждый со своим заголовком и словарём (правьте его, а не их `conf_theme.cfg`; ставьте его `EDITION_DATE`, когда они меняются). |

```
python3 tools/check_theme.py themes/*
python3 tools/png8.py themes/thm_MyTheme
python3 tools/mirror_theme.py "themes/thm_Adapt" "themes/thm_Adapt Rx" "Adapt Rx"
```
Python 3 с Pillow и numpy (`pip install pillow numpy`) для `png8.py`. Затем посмотрите вживую: в PCSX2 (System > Start File, RIPPS2.elf) с темой на виртуальном диске или на PS2.
