<h1 align="center">RIPPS2-teman</h1>

<p align="center"><b>Ge RIPPS2 ett tema utan att röra koden.</b><br>
Varje utseende i RIPPS2 är en temamapp bort: en <code>conf_theme.cfg</code>, 8-bitars PNG, typsnitt och ljud.<br>
Ingen ELF att bygga om. Lita på bygget, ge det ett tema.</p>

## Temana

| Tema | Utseende | Kräver RIPPS2 |
|---|---|---|
| **Adapt** / **Adapt Rx** | akilluminati47s Adapt (RiptOPL): varje spels bild under frostat glas (inzoomad, inte utdragen, i 16:9) med Adapts sidofält som en frostad remsa till vänster, spelets omslag i RIPPS2:s fodral med sin spegling och skivan på ena sidan, listan på klart glas på den andra (Rx byter plats på listan och fodralet och lägger LAUNCH DISC till höger i fältet, över sin skiva). Skivan sitter alltid precis under LAUNCH DISC. Infosida på klart glas med 4:3-skärmbilder, som lutar med höger spak som ett enda ark; sidövergångar, Inställningar över pelarna, inga torn på spelsidorna. Inga egna ljud (från 2026-10-12): dina rippade ljud i AUDIO-mappen spelas. Källans namn dyker upp (från build 81 som en notis: ALL GAMES, HDD GAMES...). Från utgåva 113 är de tre kategorierna glyfer i det frostade sidofältet (`category_layout=sidebar`, build 113): Vänster på listan öppnar varje kategoris låda bredvid. Från utgåva 115 är varje tema sin `conf_theme.cfg` och sin `SCR43.png`. Listans fodral visar framsidan och sedan baksidan, med övertoning; infosidan lägger sin text på motsatt sida mot listan (Adapt till höger, Adapt Rx till vänster). | build 80 |
| **RIPGRID** *(inbyggt i RIPPS2 från build 91: välj det under Inställningar > Gränssnitt > Tema)* | Adapts frostade skärm och sidofält med spelen i ett centrerat rutnät av omslag, 4x2; markeringen andas med ett mjukt sken och lutar med höger spak, spel utan omslag visar sitt serienummer i pixeltext, och Cirkel växlar mellan källorna. Att hålla höger spak i 0,42 s vänder det valda fodralet till baksidan (build 97; det förblir vänt), sidor glider in och ut med L2 / R2 eller vid kanten av en rad, spelets skiva dyker upp när det startar, och det valda spelets namn står under rutnätet i RIPPS2 Sleek Bold. Det följer med i ELF-filen och finns därför inte längre i det här paketet. | inbyggt |

Installation: kopiera en `thm_...`-mapp till en `THM`-mapp på din enhet (USB, HDD, MMCE, minneskort), som för vilket OPL-tema som helst, och välj det sedan i RIPPS2 under Inställningar > Gränssnitt > Tema, eller håll SELECT i 4,2 sekunder på spellistan för att stega mellan temana. RIPGRID och RIPFLOW finns redan där.

Varje `conf_theme.cfg` här börjar med sitt skaparhuvud (namn, skapare, skapelse- och uppdateringsdatum, tack), sedan **nyckelordlistan** ([docs/key_glossary.cfg](docs/key_glossary.cfg): varje nyckel ett tema kan använda, som kommentarer), sedan temat. Kopiera ordlistan till ditt eget temas konfiguration för att ha den till hands.

<a id="on-the-console"></a>

### På konsolen
- **Håll SELECT i 4,2 sekunder** på spellistan för att byta till nästa tema (ett snabbt tryck uppdaterar fortfarande listan).
- **Höger spak** lutar bilden: hela infosidan som ett plan, Adapts fodral och skiva, RIPGRIDs valda omslag.
- **RIPGRID** (inbyggt): styrkorset rör sig i rutnätet, en rads kant bläddrar sidan; **Cirkel** växlar mellan källorna (USB, HDD, ALL GAMES...).

<a id="make-your-own"></a>

## Gör ditt eget

**[docs/THEME_KEYS.md](docs/THEME_KEYS.md) är hela motorn, enligt RIPPS2 build 100**, allt nåbart från en temamapp:

| | Vad ett tema kan göra |
|---|---|
| **Utseende** | Paneler av frostat glas över varje spels bild, ett frostat lager över hela skärmen, sidofält, klart glas, ett omslags-**rutnät**, RIPPS2:s fodral med spegling, 4:3-skärmbilder på 16:9, brett beskurna bakgrunder, torn av eller på. |
| **Rörelse** | Lutning med höger spak som flyttar en hel sida som ett ark (eller ett omslag), övergångar mellan listan och infosidan, bilder som glider in, beskrivningar som rullar, bildspel på infosidan, källans namn som notis. |
| **Typsnitt** | 16 typsnittsplatser, din egen `.ttf` eller RIPPS2:s inbyggda typsnitt, med versaler eller inte; platserna RIPPS2 ritar sina egna sidor med, så ett tema ger även menyer, kategorifältet och visningsordet ny stil. |
| **Färg** | Temats färger och dess eget **Colors and More**: färgtema (RIPPS2, Ember, Blood, Ectoplasm, Amethyst, Bone), kategorifält, tips, glyfer, kategoriernas ordning. Användaren har alltid sista ordet. |
| **Bilder** | Vilken som helst av RIPPS2:s egna bilder (knappglyfer, märken, laddningstecken, det flygande märket, PS1- / PS2-logotyperna) ersatt genom att skicka med en PNG med samma namn. |
| **Ljud** | En `sound/`-mapp med vilken som helst av de 15 händelserna (start, markör, bekräfta, sida in och ut, start av spel, skiva...) och `sound/bgm.ogg` för egen musik. |

## Verktygslådan

| | |
|---|---|
| [AGENTS.md](AGENTS.md) | Reglerna: läs dem först. |
| [docs/THEME_KEYS.md](docs/THEME_KEYS.md) | Allt RIPPS2:s motor gör för ett tema: nycklar, element, typsnitt, effekter, bilder, ljud. |
| [docs/THEME_ENGINE_RiptOPL.md](docs/THEME_ENGINE_RiptOPL.md) | Motorn därunder (RiptOPLs referens). |
| [docs/key_glossary.cfg](docs/key_glossary.cfg) | Varje nyckel på en sida, som `#`-kommentarer: ordlistan överst i varje `conf_theme.cfg` här. |
| `tools/check_theme.py` | Kommer det att laddas? Numrering, typer, saknade filer, felplacerade nycklar, värden RIPPS2 känner till, 8-bitarsbilder. |
| `tools/mirror_theme.py` | Skissar ett temas spegelvända layout. |
| `tools/png8.py` | Gör varje bild till en 8-bitars palett-PNG: RIPPS2 behåller dem som 8-bitars texturer, en fjärdedel av VRAM. |
| `tools/gen_adapt_family.py` | Skriver Adapt och Adapt Rx från en layout, var och en med sitt huvud och ordlistan (redigera den, inte deras `conf_theme.cfg`; sätt dess `EDITION_DATE` när de ändras). |

```
python3 tools/check_theme.py themes/*
python3 tools/png8.py themes/thm_MyTheme
python3 tools/mirror_theme.py "themes/thm_Adapt" "themes/thm_Adapt Rx" "Adapt Rx"
```
Python 3 med Pillow och numpy (`pip install pillow numpy`) för `png8.py`. Titta sedan på det på riktigt: i PCSX2 (System > Start File, RIPPS2.elf) med temat på dess virtuella enhet, eller på en PS2.
