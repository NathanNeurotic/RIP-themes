<h1 align="center">RIPPS2 主題</h1>

<p align="center"><b>不碰程式碼，就能為 RIPPS2 換主題。</b><br>
RIPPS2 的每種外觀都只差一個主題資料夾：一個 <code>conf_theme.cfg</code>、8 位元 PNG、字型和音效。<br>
不必重新編譯 ELF。交給建置，替它換上主題。</p>

<a id="the-themes"></a>

## 主題

| 主題 | 外觀 | 需要的 RIPPS2 |
|---|---|---|
| **Adapt** / **Adapt Rx** | akilluminati47 的 Adapt（RiptOPL）：每個遊戲的美術圖在霧面玻璃下（在 16:9 中放大而非拉伸），左側是 Adapt 的側邊欄，呈霧面條帶；一邊是裝在 RIPPS2 遊戲盒裡的遊戲封面及其倒影和光碟，另一邊是透明玻璃上的清單（Rx 交換清單和遊戲盒，並把 LAUNCH DISC 放在側邊欄右側、光碟上方）。光碟總在 LAUNCH DISC 的正下方。資訊頁是帶 4:3 截圖的透明玻璃，用右類比搖桿像一張紙一樣傾斜；頁面間有轉場，設定畫面在柱子之上，遊戲頁沒有塔。沒有自帶音效（自 2026/10/12 起）：播放你擷取到 AUDIO 資料夾的聲音。來源名稱會彈出（自 build 81 起以提示形式：ALL GAMES、HDD GAMES...）。自第 113 版起，三個分類是霧面側邊欄中的圖示（`category_layout=sidebar`，build 113）：在清單上按左，會在旁邊打開各自的抽屜。自第 115 版起，每個主題只有它的 `conf_theme.cfg` 和 `SCR43.png`。清單中的遊戲盒先顯示正面封面，再以交叉淡化顯示背面；資訊頁把文字放在與清單相反的一側（Adapt 在右，Adapt Rx 在左）。 | build 80 |
| **RIPGRID** *（自 build 91 起內建於 RIPPS2：在 設定 > 介面 > 主題 中選擇）* | Adapt 的霧面畫面和側邊欄，遊戲以置中的 4x2 封面格線排列；選中項帶柔和光暈呼吸，並隨右類比搖桿傾斜，沒有封面的遊戲以像素字型顯示序號，圓圈鍵切換來源。按住右類比搖桿 0.42 秒會把選中的遊戲盒翻到背面（build 97；保持翻轉），頁面隨 L2 / R2 或在一列的邊緣滑入滑出，啟動時遊戲光碟會彈出，選中遊戲的名稱以 RIPPS2 Sleek Bold 顯示在格線下方。它隨 ELF 一起提供，所以不再包含在這個套件裡。 | 內建 |

安裝：把一個 `thm_...` 資料夾複製到你裝置（USB、HDD、MMCE、記憶卡）上的 `THM` 資料夾中，和任何 OPL 主題一樣；然後在 RIPPS2 的 設定 > 介面 > 主題 中選擇，或在遊戲清單上按住 SELECT 4.2 秒依序切換主題。RIPGRID 和 RIPFLOW 已經在裡面。

這裡的每個 `conf_theme.cfg` 都以建立標頭開頭（名稱、作者、建立和更新日期、致謝），接著是 **鍵名詞彙表**（[docs/key_glossary.cfg](docs/key_glossary.cfg)：主題能用的每個鍵，以註解形式），最後是主題本身。把詞彙表複製到你自己主題的設定裡，方便隨時查閱。

<a id="on-the-console"></a>

### 在主機上
- 在遊戲清單上**按住 SELECT 4.2 秒**切換到下一個主題（短按仍然重新整理清單）。
- **右類比搖桿**讓美術圖傾斜：整個資訊頁作為一個平面、Adapt 的遊戲盒和光碟、RIPGRID 中選中的封面。
- **RIPGRID**（內建）：方向鍵在格線中移動，一列的邊緣會翻頁；**圓圈鍵**切換來源（USB、HDD、ALL GAMES...）。

<a id="make-your-own"></a>

## 自己做一個

**[docs/THEME_KEYS.md](docs/THEME_KEYS.md) 涵蓋整個引擎，截至 RIPPS2 build 100**，全部都能從主題資料夾使用：

| | 主題能做什麼 |
|---|---|
| **外觀** | 每個遊戲美術圖上方的霧面玻璃面板、全螢幕霧面層、側邊欄、透明玻璃、封面**格線**、帶倒影的 RIPPS2 遊戲盒、16:9 上的 4:3 截圖、寬幅裁切背景、開關塔。 |
| **動態** | 右類比搖桿傾斜，把整頁（或一張封面）像一張紙一樣移動；清單與資訊頁之間的轉場、柔和淡入的美術圖、捲動的簡介、資訊頁投影片、以提示形式出現的來源名稱。 |
| **字型** | 16 個字型槽，你自己的 `.ttf` 或 RIPPS2 的內建字型，可選是否大寫；這些正是 RIPPS2 繪製自身頁面所用的槽，所以主題也會改變選單、分類列和檢視詞的樣式。 |
| **顏色** | 主題的顏色以及它自己的 **Colors and More**：配色主題（RIPPS2、Ember、Blood、Ectoplasm、Amethyst、Bone）、分類列、提示、圖示、分類順序。最終決定權永遠在使用者手中。 |
| **圖片** | RIPPS2 自帶的任何圖片（按鍵圖示、徽章、載入指示、飛行標記、PS1 / PS2 標誌），只要放入同名 PNG 即可替換。 |
| **聲音** | 一個 `sound/` 資料夾，可包含 15 個事件中的任何一個（開機、游標、確認、進出頁面、啟動、光碟...），以及用於自帶音樂的 `sound/bgm.ogg`。 |

<a id="the-kit"></a>

## 工具組

| | |
|---|---|
| [AGENTS.md](AGENTS.md) | 規則：請先讀。 |
| [docs/THEME_KEYS.md](docs/THEME_KEYS.md) | RIPPS2 引擎為主題所做的一切：鍵、元素、字型、特效、圖片、聲音。 |
| [docs/THEME_ENGINE_RiptOPL.md](docs/THEME_ENGINE_RiptOPL.md) | 底層的引擎（RiptOPL 的參考文件）。 |
| [docs/key_glossary.cfg](docs/key_glossary.cfg) | 所有鍵都在一頁上，以 `#` 註解形式：就是這裡每個 `conf_theme.cfg` 開頭的詞彙表。 |
| `tools/check_theme.py` | 能載入嗎？編號、類型、缺少的檔案、放錯位置的鍵、RIPPS2 認得的值、8 位元圖片。 |
| `tools/mirror_theme.py` | 草擬主題的左右鏡像版面。 |
| `tools/png8.py` | 把每張圖片轉成 8 位元調色盤 PNG：RIPPS2 以 8 位元材質保存，只占四分之一的 VRAM。 |
| `tools/gen_adapt_family.py` | 從一個版面寫出 Adapt 和 Adapt Rx，各帶標頭和詞彙表（改這個檔案，不要改它們的 `conf_theme.cfg`；變動時設定它的 `EDITION_DATE`）。 |

```
python3 tools/check_theme.py themes/*
python3 tools/png8.py themes/thm_MyTheme
python3 tools/mirror_theme.py "themes/thm_Adapt" "themes/thm_Adapt Rx" "Adapt Rx"
```
`png8.py` 需要帶 Pillow 和 numpy 的 Python 3（`pip install pillow numpy`）。然後真正看一看：在 PCSX2（System > Start File，RIPPS2.elf）裡把主題放在虛擬磁碟上，或在 PS2 上。
