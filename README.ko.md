<h1 align="center">RIPPS2 테마</h1>

<p align="center"><b>코드를 건드리지 않고 RIPPS2를 꾸미세요.</b><br>
RIPPS2의 모든 모습은 테마 폴더 하나면 됩니다: <code>conf_theme.cfg</code>, 8비트 PNG, 글꼴, 사운드.<br>
ELF를 다시 빌드할 필요가 없습니다. 빌드를 믿고, 테마를 입히세요.</p>

## 테마

| 테마 | 모습 | 필요한 RIPPS2 |
|---|---|---|
| **Adapt** / **Adapt Rx** | akilluminati47의 Adapt(RiptOPL): 각 게임의 아트를 반투명 유리 아래에(16:9에서 늘리지 않고 확대), 왼쪽에 Adapt의 사이드바를 반투명 띠로, 한쪽에는 반사가 있는 RIPPS2 케이스 속 게임 표지와 디스크, 다른 쪽에는 투명 유리 위의 목록(Rx는 목록과 케이스를 바꾸고 LAUNCH DISC를 바 오른쪽, 디스크 위에 둡니다). 디스크는 항상 LAUNCH DISC 바로 아래에 있습니다. 정보 페이지는 4:3 스크린샷이 있는 투명 유리이며 오른쪽 스틱으로 한 장처럼 기울어집니다. 페이지 전환, 기둥 위의 설정, 게임 페이지에는 타워 없음. 자체 사운드 없음(2026/10/12부터): AUDIO 폴더에 립한 소리가 납니다. 소스 이름이 튀어나옵니다(build 81부터 토스트로: ALL GAMES, HDD GAMES...). 에디션 113부터 세 카테고리는 반투명 사이드바의 글리프입니다(`category_layout=sidebar`, build 113): 목록에서 왼쪽을 누르면 각 카테고리의 서랍이 옆에 열립니다. 에디션 115부터 각 테마는 자기 `conf_theme.cfg`와 `SCR43.png`뿐입니다. 목록의 케이스는 앞표지, 다음 뒤표지를 크로스페이드로 보여 주고, 정보 페이지는 텍스트를 목록 반대편에 둡니다(Adapt는 오른쪽, Adapt Rx는 왼쪽). | build 80 |
| **RIPGRID** *(build 91부터 RIPPS2에 내장: 설정 > 인터페이스 > 테마에서 선택)* | Adapt의 반투명 화면과 사이드바에 게임을 가운데 정렬한 4x2 표지 격자로; 선택 항목은 은은한 빛으로 숨 쉬고 오른쪽 스틱으로 기울며, 표지가 없는 게임은 시리얼을 픽셀 글자로 보여 주고, 동그라미로 소스를 바꿉니다. 오른쪽 스틱을 0.42초 유지하면 고른 케이스가 뒤표지로 뒤집히고(build 97; 그대로 유지), 페이지는 L2 / R2나 줄 끝에서 들어오고 나가며, 실행할 때 게임 디스크가 튀어나오고, 고른 게임의 이름은 격자 아래 RIPPS2 Sleek Bold로 표시됩니다. ELF 안에 들어 있어서 이 팩에는 더 이상 없습니다. | 내장 |

설치: `thm_...` 폴더를 드라이브(USB, HDD, MMCE, 메모리 카드)의 `THM` 폴더에 복사한 뒤(여느 OPL 테마처럼), RIPPS2의 설정 > 인터페이스 > 테마에서 고르거나, 게임 목록에서 SELECT를 4.2초 누르고 있으면 테마를 차례로 바꿉니다. RIPGRID와 RIPFLOW는 이미 들어 있습니다.

여기 있는 모든 `conf_theme.cfg`는 생성 헤더(이름, 만든 이, 만든 날짜와 갱신 날짜, 크레딧), 이어서 **키 용어집**([docs/key_glossary.cfg](docs/key_glossary.cfg): 테마가 쓸 수 있는 모든 키를 주석으로), 그다음 테마로 시작합니다. 용어집을 자기 테마 설정에 복사해 두면 편합니다.

<a id="on-the-console"></a>

### 콘솔에서
- 게임 목록에서 **SELECT를 4.2초 누르고 있으면** 다음 테마로 넘어갑니다(짧게 누르면 지금처럼 목록을 새로 고칩니다).
- **오른쪽 스틱**으로 아트가 기울어집니다: 정보 페이지 전체를 한 면으로, Adapt의 케이스와 디스크, RIPGRID의 선택된 표지.
- **RIPGRID**(내장): 방향키로 격자를 이동하고 줄 끝에서 페이지를 넘깁니다. **동그라미**로 소스를 바꿉니다(USB, HDD, ALL GAMES...).

## 직접 만들기

**[docs/THEME_KEYS.md](docs/THEME_KEYS.md)는 RIPPS2 build 100 기준의 엔진 전부이며**, 모두 테마 폴더에서 쓸 수 있습니다:

| | 테마가 할 수 있는 일 |
|---|---|
| **모습** | 각 게임 아트 위의 반투명 유리 패널, 전체 화면 반투명 레이어, 사이드바, 투명 유리, 표지 **격자**, 반사가 있는 RIPPS2 케이스, 16:9 위의 4:3 스크린샷, 넓게 잘라 낸 배경, 타워 켜기·끄기. |
| **움직임** | 한 페이지 전체(또는 표지 하나)를 한 장처럼 움직이는 오른쪽 스틱 기울기, 목록과 정보 페이지 사이 전환, 부드럽게 들어오는 아트, 흐르는 설명, 정보 페이지 슬라이드쇼, 토스트로 뜨는 소스 이름. |
| **글꼴** | 글꼴 슬롯 16개, 자신의 `.ttf`나 RIPPS2 내장 서체, 대문자로 쓸지 말지까지; RIPPS2가 자기 페이지를 그리는 슬롯이라, 테마가 메뉴, 카테고리 바, 보기 단어의 스타일도 바꿉니다. |
| **색** | 테마의 색과 자체 **Colors and More**: 색 테마(RIPPS2, Ember, Blood, Ectoplasm, Amethyst, Bone), 카테고리 바, 힌트, 글리프, 카테고리 순서. 마지막 결정은 항상 사용자에게 있습니다. |
| **이미지** | RIPPS2 자체 이미지(버튼 글리프, 배지, 로딩 표시, 날아다니는 마크, PS1 / PS2 로고)는 같은 이름의 PNG를 넣기만 하면 바뀝니다. |
| **사운드** | 15개 이벤트(부팅, 커서, 확인, 페이지 진입과 이탈, 실행, 디스크...) 중 무엇이든 담는 `sound/` 폴더와 자체 음악용 `sound/bgm.ogg`. |

## 키트

| | |
|---|---|
| [AGENTS.md](AGENTS.md) | 규칙: 먼저 읽으세요. |
| [docs/THEME_KEYS.md](docs/THEME_KEYS.md) | RIPPS2 엔진이 테마를 위해 하는 모든 일: 키, 요소, 글꼴, 효과, 이미지, 사운드. |
| [docs/THEME_ENGINE_RiptOPL.md](docs/THEME_ENGINE_RiptOPL.md) | 그 아래의 엔진(RiptOPL 레퍼런스). |
| [docs/key_glossary.cfg](docs/key_glossary.cfg) | 모든 키를 한 페이지에 `#` 주석으로: 여기 있는 각 `conf_theme.cfg` 맨 위의 용어집. |
| `tools/check_theme.py` | 불러와질까? 번호, 타입, 빠진 파일, 잘못된 위치의 키, RIPPS2가 아는 값, 8비트 이미지. |
| `tools/mirror_theme.py` | 테마의 좌우 반전 레이아웃 초안을 만듭니다. |
| `tools/png8.py` | 모든 이미지를 8비트 팔레트 PNG로: RIPPS2는 이를 8비트 텍스처로, VRAM의 4분의 1로 보관합니다. |
| `tools/gen_adapt_family.py` | 하나의 레이아웃에서 Adapt와 Adapt Rx를 각각 헤더와 용어집과 함께 씁니다(이 파일을 고치고, 그들의 `conf_theme.cfg`는 고치지 마세요; 바뀌면 `EDITION_DATE`를 설정). |

```
python3 tools/check_theme.py themes/*
python3 tools/png8.py themes/thm_MyTheme
python3 tools/mirror_theme.py "themes/thm_Adapt" "themes/thm_Adapt Rx" "Adapt Rx"
```
`png8.py`에는 Pillow와 numpy가 있는 Python 3(`pip install pillow numpy`). 그다음 실제로 보세요: 테마를 가상 드라이브에 둔 PCSX2(System > Start File, RIPPS2.elf)에서, 또는 PS2에서.
