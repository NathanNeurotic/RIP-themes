### ເທິງເຄື່ອງ
- **ກົດ SELECT ຄ້າງ 4,2 ວິນາທີ** ໃນລາຍການເກມເພື່ອໄປທີມຖັດໄປ (ກົດສັ້ນໆຍັງໂຫຼດລາຍການໃໝ່ຄືເກົ່າ).
- **ຄັນໂຍກຂວາ** ອຽງພາບ: ໜ້າຂໍ້ມູນທັງໝົດເປັນລະນາບດຽວ, ກ່ອງ ແລະ ແຜ່ນຂອງ Adapt, ໜ້າປົກທີ່ເລືອກຂອງ RIPGRID.
- **RIPGRID** (ມີໃນຕົວ): ປຸ່ມທິດທາງເລື່ອນໃນຕາໜ່າງ, ຂອບແຖວພິກໜ້າ; **ວົງມົນ** ປ່ຽນແຫຼ່ງ (USB, HDD, ALL GAMES...).
